SECRETOS TODAY

Una plataforma propia sobre una base compatible.

La primera era de SecretOS está planteada alrededor del ecosistema Android/AOSP, permitiendo aprovechar compatibilidad de aplicaciones, control del sistema y una transición progresiva mientras GAMMS desarrolla sus propias capas, servicios y herramientas.

En desarrollo

Android / AOSP foundation

SecretOS 1.x se concibe sobre una base Android moderna. La referencia de trabajo usada para la generación inicial es Android 15, manteniendo compatibilidad APK y el ecosistema Android como punto de partida.

En desarrollo

Secret layer

La identidad de SecretOS no depende solo del framework base: UI, servicios, configuración, privacidad, administración, Setup Wizard y aplicaciones del ecosistema se construyen como una experiencia propia.

Dirección actual

ARM first

La era inicial permanece orientada a hardware ARM/Android existente. La migración a GMA-64 pertenece a una etapa futura y no se presenta como una capacidad disponible hoy.

ONE EXPERIENCE

SecretOS debe sentirse como SecretOS.

La plataforma combina identidad visual, servicios compartidos y aplicaciones del ecosistema para mantener una experiencia consistente desde la primera pantalla hasta la operación diaria.

En desarrollo

Junix UI

Lenguaje visual de GAMMS para superficies modernas, profundidad, translucidez, movimiento y continuidad entre dispositivos. Es la capa de experiencia, no la arquitectura del sistema.

En desarrollo

PGS graphics

PGS es el nombre actual del componente gráfico antes conocido como SGS dentro del trabajo de SecretOS. Su objetivo es sostener una experiencia visual propia y evolucionar junto a Junix UI.

En desarrollo

Secret Suite

SecretChat, SecretHub, SecretNotes, SecretPlayer, SecretMeet, SecretKeyboard, SecretPay, SecretMail y SecretMusic forman la familia de aplicaciones conectadas del ecosistema.

Identidad

SecretCat

SecretCat es la mascota oficial asociada a SecretOS y al ecosistema GAMMS. En el sistema puede aparecer en onboarding, material de marca y experiencias de bienvenida sin convertir la interfaz completa en una temática infantil.

SERVICES & COMPATIBILITY

Compatibilidad sin renunciar a una plataforma propia.

La estrategia de SecretOS separa la base abierta del sistema de los servicios que dependen de terceros. Eso permite desarrollar una experiencia GAMMS mientras se evalúan distintas opciones de compatibilidad para cada mercado y dispositivo.

En desarrollo

Secret / Junix Services

Servicios propios para identidad, sincronización, continuidad, comunicaciones y funciones compartidas entre las aplicaciones Secret.

Opcional / por dispositivo

Google Mobile Services

GMS requiere certificación y acuerdos correspondientes para dispositivos comerciales compatibles. SecretOS no debe presentar GMS como parte automática de una compilación AOSP.

Compatibilidad evaluada

microG

microG se ha considerado como alternativa de compatibilidad para ciertos escenarios, pero no garantiza equivalencia total con Play Services, especialmente en integridad, pagos, banca, juegos o aplicaciones fuertemente dependientes de Google.

La estrategia enterprise prioriza predictibilidad: la compatibilidad debe validarse por aplicación y por caso de uso, en lugar de asumir un porcentaje universal de funcionamiento.

La era Android y la era nativa son dos generaciones distintas.

SecretOS no salta directamente de Android a una arquitectura propia. La transición se plantea por etapas para conservar compatibilidad, herramientas y soporte mientras madura GMA-64.

SECRETOS NATIVE

Después de Android: una plataforma diseñada alrededor de GMA-64.

La visión a largo plazo introduce SecretOS Native, construido sobre SecretOS Native Open Source Project (SNOSP) y orientado a la arquitectura GMA-64. Esta etapa está planificada y no sustituye las capacidades disponibles hoy.

Base abiertaSNOSP
HerramientasCompiler · Assembler · Emulator · sbuild

“SecretOS Open Source Project” corresponde a la era heredada basada en Android/AOSP. “SecretOS Native Open Source Project” corresponde a la futura base nativa. Son generaciones hermanas de la plataforma, no simplemente un cambio de nombre de la misma base.

NATIVE PACKAGING

De APK a Secret Package.

En la era nativa, el concepto definido para distribución de software es Secret Package, con extensión .spk. Secret Language también pertenece a esta etapa futura y se plantea como un lenguaje nacido para GMA-64, no como un reemplazo inmediato de Kotlin o del ecosistema Android.

WHAT SECRETOS IS NOT

Una visión ambiciosa, presentada con precisión.

Para mantener una documentación pública responsable, SecretOS separa capacidades presentes, trabajo activo y objetivos futuros.

Presente / base

La plataforma inicial parte de Android/AOSP y puede aprovechar el ecosistema APK.

En desarrollo

Secret experience

Junix UI, Secret Suite, Setup Wizard, servicios y administración forman el trabajo de diferenciación actual.

Futuro

GMA-64 native era

SNOSP, Secret Language, .spk y hardware GMA-64 pertenecen a la visión nativa futura y no deben presentarse como productos finalizados.
